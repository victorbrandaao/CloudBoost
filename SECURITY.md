# Security Policy

## Supported Version

CloudBoost supports the latest published release. Users should update before reporting a security issue that may already have been corrected.

## Reporting A Vulnerability

Do not publish license keys, personal information, diagnostic reports or security details in a public GitHub issue.

Send a private report to `victorbrandaotech@gmail.com` with:

- the CloudBoost and macOS versions;
- the affected feature;
- clear reproduction steps;
- the impact you observed;
- screenshots or logs with personal data removed.

Reports are reviewed before details are discussed publicly. Please allow time for validation and a safe correction.

## Scope

Useful reports include vulnerabilities involving the distributed CloudBoost app, update downloads, license validation, local data handling or the official GitHub Pages site.

CloudBoost does not authorize testing against Payhip, Gumroad, Supabase, GitHub or other third-party infrastructure beyond normal use of the app.
