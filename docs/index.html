Built for macOS

A small Mac utility for noisy gaming sessions.

I built CloudBoost after chasing the same annoying problem over and over: the connection looks fine, then a game suddenly stutters for no obvious reason.

It is not a magic FPS tool and it will not make cloud gaming identical to a local PC. It starts a focused session, reduces common macOS interruptions, and shows what may be hurting stability.

Why this exists

Average ping was not the thing bothering me.

Most of my bad cloud gaming sessions were not bad from the first second. They were fine, then uneven, then fine again.

CloudBoost is my practical answer to that: start a session, reduce the usual macOS interruptions, show the likely cause when something feels off, and restore things when you stop.

Plain notes before installing

Why does it ask for administrator permission?

Some macOS networking and process changes require approval. CloudBoost asks when a selected session needs those actions.

Does it install a kernel extension?

No. CloudBoost does not use KEXTs, hidden daemons, or permanent system patches.

Does it bypass anti-cheat or modify games?

No. CloudBoost does not inject into games, bypass anti-cheat systems, or modify game files. It focuses on the local macOS session around the game.

Will it make cloud gaming feel native?

No. Cloud and remote play still depend on servers, routing, encoding, decoding, and your network. CloudBoost is for reducing local interruptions and explaining spikes.

Can I use it without paying?

Yes. The free version includes the supported cloud services, Mac gaming profiles, manual session mode, and Balanced mode. PRO unlocks automation and advanced diagnostics.

What if macOS says the app is damaged?

Because CloudBoost is distributed outside the App Store, you may need to clear quarantine after installing: xattr -cr /Applications/"CloudBoost.app"
