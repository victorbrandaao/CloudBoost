How it works

Watch. Explain. Restore.

  1. 01Watch the Mac side

    Collect the signals that average ping hides: jitter, packet loss, route state, Wi-Fi noise and local pressure.

  2. 02Explain the warning

Does CloudBoost improve FPS?

Not directly. CloudBoost is about session stability and diagnosis. It can help when stutter comes from local macOS pressure, background tasks, power state or Wi-Fi behavior, but it does not modify the game renderer.

Does it work for native Mac games?

Yes, when the problem is around the game rather than inside it: thermal pressure, Low Power Mode, background traffic, Wi-Fi/AWDL behavior, CPU pressure or uneven local session state. CloudBoost cannot directly measure shader compilation, asset streaming, renderer frame time, engine stalls or Rosetta translation. Since version 4.2.2, it tells you when measured Mac-side signals are clean enough to investigate those causes next.

Does it work with PS Remote Play and Moonlight?

Yes. CloudBoost includes free profiles for remote play and can help identify local Mac-side causes such as Wi-Fi noise, UDP issues, route latency and background traffic.

Does it work with Shadow PC and other remote PC services?

Yes. CloudBoost can help diagnose the Mac receiving side of Shadow, remote PC and home streaming sessions: route latency, jitter, packet loss, VPN routing, UDP behavior, Wi-Fi/AWDL noise and local pressure.

Does CloudBoost work with VPNs?

CloudBoost is not a VPN service. PRO includes VPN Route Doctor, which can detect tunnel routes, blocked UDP checks and VPN-related route latency, then suggest testing with VPN off or using split tunneling for the game, client or browser.

Does it install a kernel extension?

No. CloudBoost does not install KEXTs, hidden daemons, permanent system patches, game injections or anti-cheat bypasses. Some features may ask for administrator permission because macOS requires it for temporary system-level session changes.

Why does it ask for the macOS password?

Only protected system-level actions should ask for administrator permission, such as DNS refresh, AWDL changes, Time Machine pause requests or lower-level session fixes. Viewing diagnostics and using basic profiles should not need a password.

What is Session Proof?

Session Proof is a PRO support report that can be copied from the app. It includes the selected profile, preset, Session Doctor, Session Lab, before/after summary and recent CloudBoost events. It does not include license keys, personal files, hostnames or browser history.

How many Macs can use one PRO license?

A new Payhip PRO license activates on one Mac. It can be revalidated on that same Mac. If you replace the computer, contact CloudBoost support on Discord to request a transfer instead of purchasing again.

What if macOS says the app is damaged?

Because CloudBoost is distributed outside the App Store, you may need to clear quarantine after installing: xattr -cr /Applications/"CloudBoost.app"
