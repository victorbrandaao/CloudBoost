macOS 12+ · Intel + Apple Silicon · Versión preliminar 5.0.0

Esta descarga es la versión preliminar pública 5.0.0. Las nuevas pruebas de reparación Wi-Fi siguen en desarrollo.

Instala la versión preliminar

Abre el DMG y arrastra CloudBoost a Aplicaciones. Abre la app y busca su icono en la barra de menús de macOS.

Elige a qué juegas

Selecciona tu servicio o juego y empieza con Equilibrado. El flujo básico Free funciona sin cuenta.

Prueba una sesión PRO completa

Elige “Iniciar prueba PRO de 3 sesiones” en la app. Juega al menos un minuto y termina la sesión para restaurar ajustes y revisar el resultado. No necesitas tarjeta.

Una sesión de prueba cuenta después de un minuto. Free sigue disponible al terminar las tres sesiones PRO.

Antes de instalar

CloudBoost se distribuye de forma independiente y aún no está notarizado con un Apple Developer ID. Lee el Centro de Confianza antes de abrirlo. macOS puede pedir autorización de administrador para acciones seleccionadas del sistema.
