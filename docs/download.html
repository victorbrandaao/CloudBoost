Homebrew

Install or update from the public CloudBoost tap.

brew tap victorbrandaao/cloudboost
brew install --cask cloudboost

Later, run brew upgrade --cask cloudboost.

Before opening

Requirements and security notes.

  • System: macOS 12 Monterey or later.
  • Hardware: Intel and Apple Silicon are included in the same universal app.
  • Distribution: CloudBoost is distributed independently and is not currently notarized with an Apple Developer ID.
  • Protected actions: macOS may request an administrator password only when a selected temporary system action requires it.
  • Updates: the in-app updater verifies SHA256 and an Ed25519 package signature before replacing the app in Applications.
If macOS says the app is damaged

Move CloudBoost to Applications, then run xattr -cr /Applications/CloudBoost.app in Terminal. This clears the download quarantine flag; it does not disable macOS security globally.
