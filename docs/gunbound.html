GunBound GIS on an M1 Mac with Wine

The CloudBoost maintainer signed in and entered the game on one Mac M1 using Wine Staging 11.20, DXVK for macOS and launcher 1.1.0.1123. The community script still needs a complete test on a second Mac.

From Windows files to the launcher

  1. On Windows, copy the installed GunBound folder. From ProgramData, keep only installed.json and environment.
  2. On your Mac, install Rosetta and follow the guide to run the Wine setup script with your own copies.
  3. In CloudBoost 5.1.1, open Session Center → GunBound GIS. Choose the Wine folder and open the local launcher after the check passes.

Before you start

Player questions.

Is there a partnership with GunBound GIS?

No. CloudBoost is an independent project with no partnership, affiliation or endorsement from GunBound GIS, Softnyx or Bratty Studios.

Has the profile been validated with the game client?

The CloudBoost maintainer signed in and entered the game on one Mac M1 using Wine Staging 11.20, DXVK for macOS and launcher 1.1.0.1123. The community script still needs a complete test on a second Mac. Read the Wine guide.

Does CloudBoost lower ping or increase FPS?

There is no such promise. The goal is to help understand network and Mac signals. Measured route latency is not necessarily the game server ping. The app does not modify the client or provide aiming assistance.

Do I need PRO to get started?

No. You can explore the basic profile for free. PRO adds complete session history to compare signals over time.
