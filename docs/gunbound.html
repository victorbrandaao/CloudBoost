Get started in three steps

  1. Download CloudBoost for macOS 12 or later and select GunBound GIS manually.
  2. Record a baseline before playing, then compare the same route during your session.
  3. Note when the issue occurred and share your Mac model, macOS version and connection type. Remove IP addresses and personal data from reports.

What this profile can show

Early profile: automatic process detection still needs validation. Measured route latency is not necessarily the game server ping. The app does not modify the client or provide aiming assistance; it promises neither extra FPS nor lower ping. Compatibility with the client and its anti-cheat has not yet been validated.
