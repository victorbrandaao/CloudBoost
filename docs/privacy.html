Privacy

Simple analytics, only with your permission.

CloudBoost does not sell personal data, run advertising pixels, inspect games or upload Session Proof reports automatically.

Website analytics

The site asks before loading Google Analytics. If you allow it, CloudBoost measures aggregate page visits and voluntary actions such as downloads, PRO checkout opens, Discord support, Session Review interest and public review links. This helps identify useful pages, languages and referral sources.

You can decline the prompt. To change a previous choice, clear this site's local storage and reload the page.

Optional Anonymous Stats in the app

Anonymous Stats is off until you choose to enable it inside CloudBoost. When enabled, the app may send an app-generated install identifier, a temporary session identifier, app and macOS versions, selected game or service profile, Free or PRO state, and product events such as session start/stop, diagnostics, updates, locked feature interest and license success or failure. Event properties can include session duration, preset, score, issue category and UDP summary.

This telemetry does not include the license key, personal files, browser history, hostnames, game contents or a Session Proof report. You can turn Anonymous Stats off in the app at any time.

License validation

License validation is required only when activating or periodically checking PRO access. The key you enter is sent over HTTPS to the CloudBoost validation service and Payhip. The database stores a SHA-256 hash of the normalized key rather than the raw key, along with the provider, product entitlement, status, Payhip customer email when returned, an app-specific device identifier, and activation and validation timestamps. New Payhip licenses are limited to one Mac; revalidation on that same Mac remains allowed, and transfers are handled through support.

Existing Gumroad licenses continue to use the legacy validation path supported by the app. Payment details are handled by the checkout provider and are not stored by CloudBoost.

Services and control

CloudBoost uses GitHub Pages for this website, Google Analytics only after website consent, Supabase for optional product telemetry and Payhip license records, and Payhip or Gumroad for checkout and license verification.

CloudBoost does not sell this data. For a data question or deletion request, contact support through Discord. Diagnostic reports are shared only when you deliberately copy and send them.
