Before you buy

Does PRO guarantee more FPS or lower ping?

No. CloudBoost observes the Mac and selected network test targets and can apply temporary local session actions. It cannot fix an ISP route, overloaded remote server, shader compilation or game engine. It does not modify games or bypass anti-cheat.

Is this a subscription?

No. US$10 buys the CloudBoost 4.x PRO license for one Mac. Checkout is handled by Payhip. The purchase provides an activation key; download the app separately from the official download page.

What happens when the trial ends?

Free remains available. Only sessions lasting at least one minute consume the trial. The final trial result remains visible before the app returns to Free essentials.

What if I replace my Mac?

Contact CloudBoost support to request a license transfer before buying another key.

What should I know about installation?

CloudBoost is distributed independently and is not currently Developer ID signed or notarized. The download page explains installation and package verification. Protected temporary actions may require macOS administrator authorization.
