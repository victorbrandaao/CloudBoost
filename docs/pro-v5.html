What does this add to the game’s own overlay?

Keep GeForce NOW or Moonlight’s overlay open for stream FPS, decoding and server statistics. CloudBoost adds Mac-side context and selected temporary system actions with restoration. Its route probes can point to the next local check; they are not the game server’s telemetry.
