Privacidade

Análise simples, apenas com sua autorização.

O CloudBoost não vende dados pessoais, não executa pixels de publicidade, não inspeciona jogos e não envia relatórios automaticamente.

Análise do site

O site solicita permissão antes de carregar o Google Analytics. Se você autorizar, o CloudBoost mede acessos agregados à página e ações voluntárias como downloads, aberturas de checkout PRO, suporte no Discord e links de avaliações públicas.

Você pode recusar a solicitação. Para alterar uma escolha anterior, limpe o armazenamento local deste site no seu navegador e recarregue a página.

Estatísticas Anônimas Opcionais no app

As estatísticas anônimas ficam desativadas até que você escolha ativá-las dentro do CloudBoost. Quando ativadas, o aplicativo pode enviar um identificador de instalação anônimo, versão do app e do macOS, perfil de jogo selecionado e eventos do produto.

Esta telemetria não inclui chave de licença, arquivos pessoais, histórico de navegação ou relatórios de sessão. Você pode desativar as estatísticas no app a qualquer momento.

Validação de licença

A validação de licença é necessária apenas ao ativar ou verificar periodicamente o acesso PRO. A chave informada é enviada de forma segura via HTTPS para o serviço de validação. O banco de dados armazena um hash SHA-256 da chave em vez da chave bruta, além de um identificador específico da instalação. Novas licenças Payhip ativam em um Mac; a revalidação no mesmo Mac continua permitida e transferências são tratadas pelo suporte.

Serviços e controle

O CloudBoost utiliza o GitHub Pages para este site, Google Analytics apenas após consentimento, Supabase para telemetria opcional de produto e Payhip/Gumroad para verificação de licença.

O CloudBoost não vende estes dados. Para dúvidas ou exclusão, entre em contato via Discord.
