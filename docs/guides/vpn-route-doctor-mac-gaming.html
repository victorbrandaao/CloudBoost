VPN Route Doctor

A VPN can hide the real reason a stream feels bad.

VPNs can add route latency, block UDP checks, change NAT behavior, increase jitter, or make the game service choose a worse route.

What CloudBoost detects

  • Common VPN or tunnel interfaces on macOS.
  • Whether the default route appears to be tunneled.
  • UDP checks that fail while a VPN is active.
  • Packet loss or jitter that happens while the tunnel is active.
  • When split tunneling is a better next test than changing game settings.

What to try

Test once with VPN off. If the session improves, use split tunneling for GeForce NOW, Xbox Cloud Gaming, Boosteroid, Shadow, Moonlight, Steam Link, PS Remote Play or the browser used for cloud gaming.

If the VPN is required, prefer a nearby region and a UDP/WireGuard-style mode when your provider supports it.
