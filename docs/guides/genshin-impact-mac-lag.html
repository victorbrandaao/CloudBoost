Genshin Impact on Mac

Is the stutter coming from PlayCover, Heat, or Network?

Playing Genshin Impact on a Mac often involves using tools like PlayCover to run the iOS version, or streaming it via GeForce NOW. Both methods can suffer from frustrating stutters and lag spikes if not optimized.

Separating Local Pressure from Network Jitter

When Genshin Impact drops frames during combat, the root cause depends on how you are playing:

  • PlayCover (Local): Running high graphics on an iOS-translated app can push Apple Silicon Macs into Thermal Throttling. When the Mac gets too hot, it drops CPU speeds, causing immediate FPS loss during intense domain fights.
  • GeForce NOW / Cloud (Network): If streaming, macOS background Wi-Fi/AWDL discovery scans cause 15–50 ms jitter spikes. This makes dodging and character swapping feel delayed, even with good ping.
  • Low Power Mode: Apple Silicon Macs cap performance heavily when Low Power Mode is on.

What to check for Genshin Impact sessions

  • Check macOS Thermal Pressure to ensure your Mac isn't actively throttling (especially if using PlayCover on 120fps mode).
  • Turn off Low Power Mode when playing on battery or connected to a charger.
  • If streaming over Wi-Fi, disable location services and AirDrop discovery scans during your session to prevent AWDL jitter.
