Moonlight / Steam Link

Home streaming still needs a clean path.

Moonlight and Steam Link depend on both sides: host machine load, network path, Mac Wi-Fi behavior, display settings and local background activity.

Isolate a short latency burst

Average ping is not enough for home streaming. A brief Wi-Fi scan, AWDL event, sync upload or host-side frame-time spike can interrupt delivery without changing the long-term average very much.

Use the Spike Timeline to mark when the burst happened, then compare the timestamp with active sync, backup, launcher and capture processes. CloudBoost can report known Mac-side pressure, but host encoding time still needs to be checked in Moonlight/Sunshine statistics.

Useful checks

  • Use Ethernet on the host PC or console first.
  • Keep the Mac on a strong 5 GHz/6 GHz signal or use Ethernet.
  • Watch for AWDL/AirDrop/Handoff interruptions on Wi-Fi.
  • Reduce stream bitrate/resolution while testing stability.
  • Check the host load separately from the Mac receiving the stream.

Where CloudBoost helps

CloudBoost helps with the Mac receiving side: local pressure, AWDL/Wi-Fi behavior, background traffic signals, jitter and support-ready reports.

It cannot pause every third-party sync service automatically or inspect the host renderer. Session Proof makes the receiving-side evidence easier to compare with host statistics.
