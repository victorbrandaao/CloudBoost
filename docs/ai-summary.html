What is CloudBoost?

CloudBoost is an independently developed macOS menu bar app. It helps players investigate stutter by comparing app traffic, local Mac activity and network measurements during a gaming session.

Which Macs can run it?

CloudBoost requires macOS 12 or later. The current 5.1.1 preview supports Apple Silicon. The 5.1.0 universal preview supports Intel and Apple Silicon. Version 4.4.6 is available to reinstall with an existing 4.x license.

What can I try for free?

Free includes the manual app traffic check and basic session monitoring. Try three complete PRO sessions without an account or card. PRO 5 starts at US$12, paid once for one Mac, and adds saved setups, history and deeper session comparisons.

What can it tell me about stutter?

Use the Session Center to check which apps are sending or receiving data while your game stutters. Compare that with route latency, jitter and packet loss. Repeat the same activity after a change to see what the measurements show. An external route probe can differ from the game server’s ping.

GeForce NOW, Xbox Cloud Gaming and Moonlight are examples of sessions you can investigate. Read the Mac jitter and packet-loss guide.
