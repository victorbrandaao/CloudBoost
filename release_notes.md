CloudBoost 3.1.3 adds a clearer stability layer for cloud and Mac gaming sessions.

### What's New in 3.1.3

* **Lag Inspector:** CloudBoost now explains likely lag-spike causes in plain language, including background traffic, jitter, packet loss, Wi-Fi/AWDL behavior, thermal pressure, and Low Power Mode.
* **Session Score:** PRO sessions now get a simple 0-100 stability score with the main issue detected.
* **UDP Probe:** PRO diagnostics include a lightweight UDP-based probe so the app is not relying only on TCP-style latency checks.
* **Cleaner interface:** The popover has more room, clearer sections, quieter copy, and a more professional visual rhythm.
* **Better analytics:** Anonymous telemetry can now track session scores, main issues, PRO funnel events, and update/download events when users opt in.
* **Free profiles remain free:** GeForce NOW, xCloud, Boosteroid, Moonlight, VoidLink, Local Game, Steam, Epic Games, and Battle.net remain available in the free version.

### Installation

1. Go to the **Assets** section below and download **CloudBoost_v3.1.3.dmg**.
2. Open the `.dmg` and drag **CloudBoost.app** to your `/Applications` folder.

> **Note on macOS Gatekeeper:**
> Because this is an independently signed tool, macOS might show an "App is damaged" warning on first launch. To clear the quarantine flag, open Terminal and run:
> ```bash
> xattr -cr /Applications/"CloudBoost.app"
> ```

### Free vs PRO

The free version includes all cloud gaming and Mac gaming profiles, manual boost, Balanced mode, AWDL Guard rollback protection, and basic session status.

CloudBoost PRO unlocks Auto-Detect, Auto Boost, Smart Boost, Stability Guard, Lag Inspector with UDP Probe, Session Score, Heat Guard, Keep Alive, Competitive and Smooth presets, diagnostics export, and before/after session history.

Existing PRO customers keep access to the PRO features they already purchased.
