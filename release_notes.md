CloudBoost 4.0.4 adds CrossOver/Whisky-aware diagnostics to PRO.

Free keeps core cloud, remote play, native Mac, and competitive profiles, manual Balanced sessions, basic signal checks, Stream Advisor, and rollback protection. PRO includes the complete paid toolset, now with diagnostics for CrossOver, Whisky, Wine, and Game Porting Toolkit sessions. Existing PRO customers keep access and receive the expanded PRO feature set.

### What's New

* **CrossOver/Whisky diagnostics in PRO:** CloudBoost can now treat Windows compatibility sessions as local gaming diagnostics.
* **Safe by design:** CloudBoost does not edit bottles, install translation patches, or bypass anti-cheat.
* **Better local gaming guidance:** Session Lab and Stream Signal now include advice for memory pressure, thermal pressure, Low Power Mode, background sync, and local frame-pacing risk.
* **Existing customers are protected:** current one-time PRO customers automatically receive the expanded PRO feature set.
* **Free remains useful:** core cloud, remote play, native Mac, and competitive profiles remain free, while deeper automation and diagnostics stay in PRO.

### Free And PRO

Free is for trying CloudBoost with core cloud, remote play, native Mac, and competitive profiles, manual session mode, Balanced preset, basic signal checks, Stream Advisor, and rollback protection.

PRO is for regular use: Auto Boost, Auto-Detect, Smart Boost, Stability Guard, HUD, AWDL Guard+, Session Doctor full reports, Session Lab, CrossOver/Whisky diagnostics, Stream Signal, PRO Widgets, Heat Guard, Keep Alive, advanced presets, before/after history, Session Proof export, Kernel Watch, background throttle, priority Discord support, early builds, and future lower-level networking work.

### Installation

Download **CloudBoost_v4.0.4.dmg** from the Assets section, open it, and drag **CloudBoost.app** to `/Applications`.

If macOS shows an "App is damaged" warning on first launch, open Terminal and run:

```bash
xattr -cr /Applications/"CloudBoost.app"
```

CloudBoost does not modify games, inject code, bypass anti-cheat, edit CrossOver bottles, or install kernel extensions. It focuses on temporary macOS session tuning and diagnostics around cloud, remote play, native Mac gaming, and Windows compatibility sessions on Mac.
