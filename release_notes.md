CloudBoost 3.1.2 is a focused layout fix for the 3.1.x Mac gaming release.

### What's New in 3.1.2

* **Footer is now fixed:** Info, PRO or Log, Update, and Quit stay visible at the bottom of the popover instead of living inside the scrollable content.
* **Middle content still scrolls:** The session monitor, platform cards, presets, and settings can scroll when space is tight.
* **No PRO access changes:** Existing PRO customers keep the same features and license behavior.
* **Same stability tooling:** CloudBoost still focuses on temporary, reversible session tuning for cloud and Mac gaming.

### Installation

1. Download **CloudBoost_v3.1.2.dmg** from the Assets section.
2. Open the DMG and drag **CloudBoost.app** to `/Applications`.

If macOS shows an "App is damaged" warning on first launch, clear the quarantine flag:

```bash
xattr -cr /Applications/"CloudBoost.app"
```

### Free vs PRO

The free version includes all supported cloud and Mac gaming profiles, manual boost, Balanced preset, AWDL Guard rollback protection, and basic system optimization.

CloudBoost PRO unlocks automation and advanced add-ons: Auto-Detect, Auto Boost, Smart Boost, Stability Guard, Heat Guard, Keep Alive, diagnostics export, before/after session history, and advanced presets.

Existing PRO customers keep access to every PRO feature they already purchased.
